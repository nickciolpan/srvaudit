Install

One binary. The only runtime dependency is the ssh client you already have.

$ brew install nickciolpan/tap/srvaudit

Works on macOS and on Linux — Homebrew formulae are built for both.

$ curl -fsSL https://raw.githubusercontent.com/nickciolpan/srvaudit/main/install.sh | sh

Picks the right build for your platform and verifies its published SHA-256 before installing — a missing checksum aborts the install. Set PREFIX=~/.local/bin to choose where it lands.

$ cargo install --git https://github.com/nickciolpan/srvaudit

Needs Rust 1.85 or newer for the 2024 edition.

$ srvaudit-darwin-arm64 · darwin-amd64 · linux-amd64 · linux-arm64

Every release ships four tarballs with checksums. The Linux builds are statically linked against musl, so they run on any distribution whatever its glibc.

What it actually runs

Nothing that writes. The commands you would type yourself, sent as one script to one remote sh.

QuestionCommand
What is listening?ss -tulnp — falls back to netstat -tulnp. TCP and UDP.
What containers exist?docker ps -a — falls back to podman ps -a
What services run?systemctl list-units --type=service --state=running,failed,exited
What starts at boot?systemctl list-unit-files --type=service --state=enabled
What is scheduled?crontab -l, /etc/crontab, /etc/cron.d/*, /etc/cron.{hourly,daily,weekly,monthly}, systemctl list-timers
How full is the disk?df -hPT and df -iP — space and inodes, because a full inode table fails writes while df -h still looks fine
Where did the disk go?du -shx /var/lib/*
Who am I here?uname, /etc/os-release, /proc/loadavg, /proc/meminfo, id -un

What it flags

Heuristics on a point-in-time snapshot, not a compliance scan — and every one of them is derived from output you can read in the Probes tab.

HIGH

A datastore bound to 0.0.0.0

Postgres, Redis, Mongo, Elasticsearch, kubelet, the unauthenticated Docker API on 2375. Ports 22, 80 and 443 on 0.0.0.0 are not findings — that is what they are for.

HIGH

Inodes running out

A filesystem past 85% of its inodes fails writes with ENOSPC while df -h still reports plenty of free space. Usually a directory full of tiny files.

HIGH

A cron job that pipes a download into a shell

curl … | bash on a schedule. Whoever controls that URL controls the machine, on every run.

MED

Container ports published on 0.0.0.0

Docker inserts its own iptables rules ahead of the INPUT chain, so the ufw rule you wrote does not block them. Publish to 127.0.0.1 where you can.

MED

Failed units and crash-looping containers

Plus filesystems past 80% and 90%, and units that are enabled at boot but never started.

Three decisions worth knowing about

It drives OpenSSH

Rather than reimplementing SSH. Your ~/.ssh/config aliases, ProxyJump, agent keys, certificates, FIDO tokens, 2FA prompts and known_hosts all behave exactly as they do when you type ssh yourself.

The first connection opens a ControlMaster socket in a private 0700 directory, so pressing r to refresh reuses it and never authenticates twice.

It never asks for a sudo password

--sudo uses sudo -n only. If sudo wants a password, the privileged probes are skipped and the Overview says so.

An audit tool that can hang forever on a hidden password prompt is worse than one that tells you what it could not see.

“Denied” is never “none”

Every probe records whether it succeeded, was refused, found the tool missing, or came back partial. An empty tab says either nothing here or unknown, not empty: docker ps -a — permission denied.

And a probe that returns most of an answer keeps it: du -shx /var/lib/* exits 1 when a couple of subdirectories are root-only, having correctly sized the other twenty. That is recorded as partial, with the data intact and the gap reported — not thrown away as a failure.
